# Como Contribuir

Ficamos felizes com o seu interesse em contribuir com o projeto **[Estoque 360]**! Toda ajuda é bem-vinda.

Para garantir que o projeto continue organizado, pedimos que siga algumas diretrizes simples.

## 💬 Reportando Problemas (Issues)

Se você encontrar um bug, tiver uma dúvida ou uma sugestão de melhoria, por favor, abra uma "Issue" aqui no GitHub.

* **Para Bugs:** Descreva o problema da forma mais detalhada possível. O que você esperava que acontecesse? O que realmente aconteceu? Se possível, inclua prints.
* **Para Sugestões:** Descreva sua ideia e por que você acha que ela seria boa para o projeto.

## 🚀 Fazendo Alterações no Código (Pull Requests)

Se você quer corrigir um bug ou adicionar uma nova funcionalidade, siga estes passos:

1.  **Faça um "Fork"** deste repositório (clique no botão "Fork" no canto superior direito).
2.  **Crie um novo Branch** para a sua alteração no *seu* fork:
    ```bash
    git checkout -b minha-nova-feature
    ```
3.  **Faça suas alterações** e realize os commits:
    ```bash
    git commit -m "Adiciona nova feature"
    ```
4.  **Envie (Push)** o seu branch para o seu fork:
    ```bash
    git push origin minha-nova-feature
    ```
5.  **Abra um "Pull Request"** (PR) aqui no repositório original, explicando o que você mudou.

Nós iremos revisar o seu PR o mais rápido possível. Obrigado por contribuir!
